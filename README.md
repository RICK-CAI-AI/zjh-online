# 炸金花 · 好友联机

纯娱乐、零财物。最多 9 人，能联机即开即玩。**服务端只把牌发给玩家本人**，别人永远看不到你的牌（连 F12 也拿不到）。

---

## 🚀 最快上手（同一 WiFi）

1. 双击 `start-server.cmd` 启动服务端
2. 浏览器打开 `http://localhost:3000`，进一个房间号（例如 `8888`）
3. 同一 WiFi 下的好友用 `http://10.10.104.13:3000` 打开（你的 IP 如果变了会重新显示在服务窗口），填同一个房间号
4. 你是房主，点"开局"

## 🌐 异地好友怎么玩（两选一）

### 方案 A：ZeroTier 虚拟局域网（推荐 · 已装好）

ZeroTier 是点对点（P2P）虚拟局域网，不经过任何第三方中转、不暴露真实公网 IP，比 cpolar 更快更稳。**驱动和客户端我已经在这台机器装好了**（托盘图标应该已经在桌面右下角）。你只需做几步：

**第 1 步｜去 ZeroTier 官网建一个网络（1 分钟，免费）**
1. 打开 [https://my.zerotier.com](https://my.zerotier.com) 用邮箱注册（免费）
2. 登录后点 **「Create A Network」**
3. 会生成一个 **16 位十六进制 Network ID**（形如 `a1b2c3d4e5f60708`）——**把这个 ID 记下来**

**第 2 步｜本机加入网络（二选一）**
- **方式一（最省事，推荐）**：桌面右下角找到 **ZeroTier 托盘图标**（蓝色 ∞）→ 右键 **Join Network** → 粘贴 Network ID → 确定
- **方式二（命令行）**：以管理员身份运行 `zjh-online\join-zt.bat`，按提示输入 Network ID

**第 3 步｜在控制台批准本机**
回到 [my.zerotier.com](https://my.zerotier.com) 的 Networks → 你刚建的网络 → **Members** 列表，勾选本机那台设备的 **Auth**（小方框），状态变绿 **ONLINE** 即成功。

**第 4 步｜把虚拟 IP 发给好友**
在本机 `cmd` 里跑 `ipconfig`，找 **「ZeroTier One」** 网卡，记下它的 IPv4（一般是 `10.x.x.x` 或 `192.168.x.x`）。把这个 IP 告诉好友，好友访问 `http://虚拟IP:3000` 即可。

**第 5 步｜好友加入（每人 1 次）**
- 电脑：装 ZeroTier（[官网下载](https://www.zerotier.com/download/)），托盘 Join Network 输入同一 Network ID
- 手机：应用商店搜 **ZeroTier One**，登录/直接 Join Network 输入同一 Network ID
- 你在控制台 Members 里把每个好友也勾 **Auth** 批准
- 好友打开 `http://你的虚拟IP:3000`，填同一个房间号 → 你点开局

✅ 优点：地址固定、直连零中转、不限重启、免费。最多支持几十台设备，9 人牌局绰绰有余。

### 方案 B：路由器端口映射（地址固定，可选）

你家的网络信息：

| 项 | 值 |
|---|---|
| 你的公网 IP | `115.238.52.18`（杭州电信，看着像真公网） |
| 本机内网 IP | `10.10.104.13` |
| 路由器管理地址 | `http://10.10.104.1` |

如果这个公网 IP 确实是真公网地址（电信家宽老用户通常有），做一次端口映射，地址就永久固定：

1. 浏览器进 `http://10.10.104.1`（如果进不去试 `192.168.1.1` / `192.168.0.1`）
2. 登录后找 **"虚拟服务器"** / **"端口映射"** / **"NAT 转发"** / **"Advanced -> Port Forwarding"**
3. 添加规则：
   - 外部端口：`3000`
   - 内部 IP：`10.10.104.13`
   - 内部端口：`3000`
   - 协议：`TCP`
4. 保存。然后让朋友试 `http://115.238.52.18:3000`

⚠️ 一次设置终身使用；但运营商会偶尔回收公网 IP，到时候重新查一下更新发给好友。

## 🎮 玩法

| 操作 | 规则 |
|---|---|
| 看牌 | 一旦看牌就回不去闷牌身份；本轮你下注 = 闷牌的 **2 倍** |
| 跟注 / 过牌 | 当前轮没下够就"跟注"，下够了就"过牌" |
| 加注 | 闷牌单位，必须高于当前注、不超过单注上限（可调） |
| 弃牌 | 留下继续观战到本局结束（**血战到底**） |
| 比牌 | 两两比，输家出局，牌销毁不公开。**看牌不能主动找闷牌比**，闷牌可主动找看牌 |
| 自动开牌 | 达到下注轮数上限（默认 4 轮）时自动亮牌，最大者收底池 |

## 🔒 一点关于"防偷看"的设计

- 牌型评估和发牌都在服务端，客户端只渲染
- 每个人只会收到**自己**的三张牌，别人是 `null`
- **"看牌"动作之前连你自己的牌都不发给你**——所以闷牌是真的闷，不是前端遮罩糊弄
- 弃牌者的牌在结算时仍不公开（对其他人），只有开牌 / 房主点"公布所有牌"才公开
